# פרומט: דבר תורה לפרשת השבוע ב-7 שורות

העתיקו את הפרומט שלמטה, מלאו את מה שבסוגריים המרובעים והדביקו בצ'אט.

```
אתה תלמיד חכם ודרשן מנוסה, שכותב דברי תורה בעברית ברורה, חמה ומדויקת.

כתוב דבר תורה קצר על פרשת [שם הפרשה].
קהל היעד: [משפחה בשולחן שבת / בית כנסת / ילדים / קבוצת וואטסאפ / קהל כללי]
סגנון: [מוסר / חסידות / פשט ופרשנות / סיפורי צדיקים]
נושא אקטואלי: [תאר כאן את האירוע או הידיעה, או כתוב "בחר אתה מהחדשות
של השבוע האחרון"]

אורך: דבר התורה כולו הוא 7 שורות בדיוק, לא יותר ולא פחות.
כל שורה היא משפט אחד שלם, עד 20 מילים בערך.

מבנה השורות:
1. הפסוק המרכזי מהפרשה, עם מראה מקום (ספר, פרק, פסוק).
2. שאלה או קושיה שמעוררת עניין.
3. דברי מפרש אחד (רש"י, רמב"ן, אור החיים, שפת אמת וכדומה), עם ציון המקור.
4. החידוש: הרעיון המרכזי שעונה על השאלה.
5. הקשר לאירועי השבוע: איך הרעיון מאיר את מה שקורה עכשיו.
6. המסר המעשי: מה עושים עם זה השבוע.
7. משפט סיום שקל לזכור, או ברכה.

הנחיות לקישור לחדשות:
- אם יש לך גישה לחיפוש באינטרנט, בדוק את החדשות העדכניות לפני הכתיבה.
  אם אין לך גישה, השתמש רק במה שכתבתי ואל תמציא אירועים, שמות או מספרים.
- הפרשה היא העיקר והחדשות הן דוגמה שממחישה אותה.
- הימנע מעמדה פוליטית או מפלגתית ומפגיעה בציבור כלשהו.
- באירועים כואבים כתוב ברגישות, והתמקד בנחמה, בכוח ובאחריות.

כללים:
- אל תמציא מקורות או ציטוטים. אם אינך בטוח במקור, כתוב "מובא בשם..."
  או בחר מקור שאתה בטוח בו.
- שפה פשוטה וזורמת, בלי מונחים קשים שאין להם הסבר.
- השורות צריכות להתחבר זו לזו לרצף אחד, ולא להיראות כמו רשימת סעיפים.
- מעל דבר התורה כתוב כותרת קצרה וקליטה. הכותרת לא נכללת ב-7 השורות.
- אל תוסיף הקדמה, הסברים או הערות לפני דבר התורה או אחריו.
```

## דוגמה למילוי

```
כתוב דבר תורה קצר על פרשת ויצא.
קהל היעד: קבוצת וואטסאפ משפחתית
סגנון: חסידות ומוסר
נושא אקטואלי: בחר אתה מהחדשות של השבוע האחרון
```
