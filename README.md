# Excel-courses

דף נחיתה סטטי בעברית לקורס אקסל דיגיטלי של רונן מערכות. הקבצים (`index.html`, `styles.css`, `script.js`) נמצאים בשורש המאגר ומיועדים ל-GitHub Pages מענף `main`, תיקייה `/`.

Static Hebrew landing page for Ronen Systems' digital Excel course. Site files live at the repository root and are meant to be served by GitHub Pages from branch `main`, folder `/`: https://ronen1971.github.io/Excel-courses/

## קורס בניית רשת סוכני AI / AI Agent Network course

תיקיית `ai-agents/` מכילה קורס מעשי בעברית לבניית רשת סוכני AI עם Claude: 7 מודולים, 28 שיעורים, בחנים, ומעקב התקדמות שנשמר בדפדפן. קבצי קוד Python להרצה נמצאים ב-`ai-agents/code/`.

The `ai-agents/` folder holds a hands-on Hebrew course on building multi-agent AI systems with Claude (7 modules, 28 lessons, quizzes, in-browser progress tracking), with runnable Python examples in `ai-agents/code/`: https://ronen1971.github.io/Excel-courses/ai-agents/
