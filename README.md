# Excel-courses

דף נחיתה סטטי בעברית לקורס אקסל דיגיטלי של רונן מערכות. הקבצים (`index.html`, `styles.css`, `script.js`) נמצאים בשורש המאגר ומיועדים ל-GitHub Pages מענף `main`, תיקייה `/`.

Static Hebrew landing page for Ronen Systems' digital Excel course. Site files live at the repository root and are meant to be served by GitHub Pages from branch `main`, folder `/`: https://ronen1971.github.io/Excel-courses/

## מעבדת אקסל / Excel Lab app

אפליקציית תרגול חינמית בתיקייה `app/` (https://ronen1971.github.io/Excel-courses/app/): 10 תרגילים אינטראקטיביים בעברית שבהם כותבים נוסחאות אמיתיות (SUM, IF, COUNTIF, SUMIF, VLOOKUP, ROUND ועוד) ומקבלים בדיקה מיידית. ההתקדמות נשמרת בדפדפן. אין תלות בספריות חיצוניות: מנוע הנוסחאות נמצא ב-`app/engine.js`.

A static, dependency-free practice app: a small formula engine plus 10 guided exercises, progress saved in `localStorage`.
